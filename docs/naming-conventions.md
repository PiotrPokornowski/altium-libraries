# Altium Library Naming Conventions

## General

- lowercase filenames.
- hyphens to separate words.
- no spaces and special characters.
- native Altium file extensions.
- one symbol or footprint per library file where practical.

## Symbols

- manufacturer part numbers for device-specific symbols.
- descriptive names for generic symbols.

Examples:
- stm32g431cb.SchLib
- usb-c-receptacle.SchLib
- resistor.SchLib

## Footprints

- package-based names for reusable footprints.
- dimensions and pitch where relevant.
- manufacturer part numbers for unique land patterns.

Examples:
- lqfp-48-7x7-p0.5.PcbLib
- r-0603.PcbLib
- c-0603.PcbLib

## 3D Models

- names matching their corresponding footprints where practical.
- original manufacturer models when appropriate.
