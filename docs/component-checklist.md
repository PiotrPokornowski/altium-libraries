# Component Review Checklist

Before a component is considered validated:

- [ ] Symbol checked against manufacturer datasheet
- [ ] Pin numbers verified
- [ ] Pin electrical types reviewed
- [ ] Footprint dimensions verified
- [ ] Pad numbers and pin mapping verified
- [ ] Courtyard and assembly outlines checked
- [ ] Silkscreen clearance checked
- [ ] Pin 1 orientation verified
- [ ] 3D model alignment verified, if applicable
- [ ] Manufacturer part number recorded
- [ ] Datasheet source recorded
- [ ] Changes committed to Git
